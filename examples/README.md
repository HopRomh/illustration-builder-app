# Примеры композиций

Три готовые композиции, собранные тем же pipeline, что и приложение: подбор объектов → `composeScenario` / `composeFallbackPlan` → `layoutComposition` → перекраска по ролям. Каждый пример лежит в двух форматах:

- `.svg` — векторный результат, открывается в браузере и Figma, слои и path редактируются;
- `.png` — растровое превью в размере холста (для быстрого просмотра).

| Файл | Сценарий | Схема | Размер | Формат | Состав |
| --- | --- | --- | --- | --- | --- |
| `01-metaphor-peach-L-1x1` | 1, fallback V1: «сложности в работе, которые решаются по шагам» | peach | L | 1:1 (1080×1080) | пазл (`main`), папка и ручка (`background`) |
| `02-objects-lilac-L-4x3` | 2: «книга, телефон, лампа» | lilac | L | 4:3 (1440×1080) | книга (`main`), телефон и лампа (`background`) |
| `03-objects-mint-S-1x1` | 2: «книга, телефон, лампа, папка, ручка» | mint | S | 1:1 (1080×1080) | книга (`main`), остальные (`background`) |

## Что показывает каждый пример

1. **01-metaphor-peach-L-1x1** — Сценарий 1 без LLM. Текст разобран на токены, fallback выбрал вариант V1: пазл как фокус, папка и ручка как support-объекты. Схема peach, размер L, квадратный холст.
2. **02-objects-lilac-L-4x3** — Сценарий 2 по названиям. Первый объект («книга») стал главным, остальные — фоновыми. Схема lilac, размер L, горизонтальный формат 4:3: подложка сохраняет пропорции, поля закрашены `bg-1`.
3. **03-objects-mint-S-1x1** — Сценарий 2 в размере S. Пять компактных S-объектов помещаются на квадратном холсте; схема mint. Пример показывает, что размер сцены общий и L/S не смешиваются.

## Как воспроизвести

1. Запустите приложение: `npm run dev` (и `npm run dev:api`, если нужен LLM).
2. Соберите композицию:
   - Сценарий 1: вкладка «Сценарии» → «Метафора» → текст из таблицы → «Собрать» → выберите V1;
   - Сценарий 2: вкладка «Сценарии» → «Названия объектов» → введите названия через запятую → «Собрать».
3. Выберите схему, размер и формат в тулбаре.
4. Нажмите «Экспорт SVG». Полученный файл можно открыть в браузере или Figma.
5. PNG-превью проще всего получить скриншотом холста или конвертацией SVG в растр.

## Ограничения примеров

- Это статичные снимки, а не сохранённые проекты: приложение не хранит сцены между перезагрузками.
- В примерах нет текста и подписей — только объекты и подложка, как в экспорте приложения.
- S-версии `lamp`, `puzzle`, `pen` и `tulips` — масштабированные копии L (см. основной README, раздел «Известные ограничения»).
